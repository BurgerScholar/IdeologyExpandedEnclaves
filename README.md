# Ideology Expanded: Enclaves

**Ideology Expanded: Enclaves** is a RimWorld 1.6 mod that adds persistent ideology-based communities to the world map.

## Current Status
Early alpha / active development.

### Working now
- Custom Pilgrim Camp world object
- Random enclave names, leaders, and populations
- Save/load persistence
- Caravan travel and arrival actions
- Local encounter-map generation
- Neutral pilgrim population spawning
- Inspect and developer controls

### Planned
- Generated camp layouts
- Persistent leaders, traders, healers, and recruiters
- Ideology-specific architecture
- Trading and recruitment
- Reputation and memory
- Quests and rituals
- Enclave growth, decline, conversion, and destruction

## Requirements
- RimWorld 1.6
- Ideology DLC

## Build
From the `Source` folder:

```powershell
dotnet build
```

The compiled DLL is written to `Assemblies/IdeologyExpandedEnclaves.dll`.
