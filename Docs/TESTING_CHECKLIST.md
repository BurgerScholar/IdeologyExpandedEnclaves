# Testing Checklist

## Before Every Test
- [ ] Build succeeded
- [ ] RimWorld fully restarted
- [ ] Brand-new enclave used for map-generation changes
- [ ] Developer mode enabled
- [ ] Log clear before testing

## World Object
- [ ] Camp spawns
- [ ] Marker texture displays
- [ ] Inspect opens
- [ ] Generated data appears
- [ ] Data persists after reload
- [ ] Developer removal works

## Caravan
- [ ] Right-click option appears
- [ ] Caravan travels
- [ ] Arrival message appears
- [ ] Local map generates
- [ ] Caravan enters map

## Population
- [ ] Campfire spawns
- [ ] Neutral faction used
- [ ] Pawn count matches population
- [ ] Pawns persist after reload
- [ ] No duplicates on revisit
