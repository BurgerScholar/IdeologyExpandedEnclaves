# Contributing

## Rules
1. Make one focused change at a time.
2. Build after every code change.
3. Test in RimWorld.
4. Do not commit a broken build.
5. Keep systems modular.
6. Prefix custom Def names with `IEE_`.

## Build
```powershell
dotnet build
```

## Commit examples
- `Add basic pilgrim camp layout`
- `Fix enclave data persistence`
- `Refactor caravan arrival logic`

## Bug reports should include
- RimWorld version
- Active DLC
- Mod list
- Full error log
- Steps to reproduce
- New or existing save
